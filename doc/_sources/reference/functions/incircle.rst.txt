Incircle function
=================

.. py:function:: Incircle(point1, point2, point3)

   Construct a new (non-independent) GeoGebra circle which is the
   incircle of the triangle formed by the given *point1*, *point2*,
   and *point3*.

   `GeoGebra Incircle() reference
