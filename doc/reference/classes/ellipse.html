Ellipse

class Ellipse

In the following constructors, additional keyword arguments can be provided to set properties of the new Ellipse.

Ellipse(f1, f2, a)

Construct the ellipse whose two foci are the points f1 and f2, and whose semimajor axis length is a.

Ellipse(f1, f2, s)

Construct the ellipse whose two foci are the points f1 and f2, and whose semimajor axis length is the length of the Segment s.

Ellipse(f1, f2, p)

Construct the ellipse whose two foci are the points f1 and f2, and which passes through the point p.

property center

(Get-only) The ellipse’s centre, as a wrapped GeoGebra Point.

property latex: str

(Get-only) A string of LaTeX representing the current equation of the ellipse, giving, e.g., \(5x^{2} + 9y^{2} - 10x\, = \,40\).

Note that when the ellipse happens to be a circle, the spacing specified by the LaTeX is slightly different to that specified by the LaTeX of the same circle as a Circle.

An Ellipse has the following common properties:

  • is_visible

  • color

  • color_floats

  • opacity

  • line_style

  • line_thickness

  • label_visible

  • label_style

  • caption

Where these properties are read-write, they can be set on construction by passing them as keyword arguments.
