AreParallel function
====================

.. py:function:: AreParallel(line1, line2)

   Construct a new (non-independent) GeoGebra boolean which is true or
   false according to whether the two given GeoGebra lines are
   parallel.

   If you want a snapshot of the value of this GeoGebra boolean as a
   Python ``boolean``, use code like the following:

   .. code-block:: python

      b = AreParallel(k1, k2)
      print(b.value)
      # True / False
