PerpendicularLine function
==========================

.. py:function:: PerpendicularLine(point, obj)

   Construct a new (non-independent) GeoGebra line which is the
   perpendicular line through *point* and perpendicular to *obj*,
   which must be a *line*, *segment*, or *vector*.
