PerpendicularBisector function
==============================

.. py:function:: PerpendicularBisector(point1, point2)

   Construct a new (non-independent) GeoGebra line which is the
   perpendicular bisector of the segment joining *point1* and
   *point2*.

.. py:function:: PerpendicularBisector(segment)

   Construct a new (non-independent) GeoGebra line which is the
