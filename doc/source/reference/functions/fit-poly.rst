FitPoly function
================

.. py:function:: FitPoly(points, degree)

   Construct a new GeoGebra :py:class:`FunctionGraph` which is the
   best-fit polynomial of the given *degree* for the given sequence of
   *points*.  The *points* are usually given as a Python list, but can
   be any Python iterable.
