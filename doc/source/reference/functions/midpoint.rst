Midpoint function
=================

.. py:function:: Midpoint(point1, point2)

   Construct a new (non-independent) GeoGebra point which is the
   midpoint of the segment joining *point1* and *point2*.

.. py:function:: Midpoint(obj)
   :noindex:

   Construct a new (non-independent) GeoGebra point which is the
   midpoint of the given *obj*, which must be a *circle*, and
   *ellipse*, or a *segment*.
